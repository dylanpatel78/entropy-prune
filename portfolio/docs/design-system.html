Colour

Both modes

Warm white rather than pure white, sage-grey for body, slate-blue for metadata. Starship is a neon — it belongs on dark surfaces and as a button fill, never as text on linen. Ratios are measured against each mode's ground.

Dark mode

Light mode

Three tokens fail contrast where the spec uses them. Dark #536878 sits on 9–11px mono labels but measures 3.45:1 on #080808; AA wants 4.5:1, and #7D8FA0 gives 6.0:1. Light #8A9BAA is 2.3:1 on linen — #6B7C8B reaches 3.9:1, which clears AA for 14px+ but still not for 10px labels, so mono labels in light mode should use Text secondary instead. Light Starship #C8D400 is 1.3:1 as text; it works only as a fill with #0A0A0A on it (12.1:1).

Gradient identities

6 triads

Six identities, down from twelve. Each is an analogous triad — three hues within about 90° of one another, travelling one direction around the wheel. That is the whole trick behind the smooth gradients in the references: complements never meet, so there is no muddy seam where two colours cancel. Cards stay dark in both themes.

Two treatments

Undecided

The same triad, built two ways. Fishbowl is a single 145° linear sweep through all three hues. Mesh drops each hue at a different corner as a very wide radial — 135–155% extents, so the falloff is gradual and the blends stay soft. Fishbowl reads as one light source; Mesh reads as several. Both are live until you pick.
